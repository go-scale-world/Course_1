2. **Wrong repo:** reject or redirect using REPO_MAP (`wrong-repo` label OK).

4. **Your path: commit per rule 3. Anyone else's path: Pull Request** with owner as reviewer.
5. **Commit messages say what + why.**
6. **Markdown only** except public `course-materials` (HTML carve-out in REPO_MAP).
7. **Nothing is deleted.** Move superseded files to `Archive/` with `YYYY-MM-DD_` prefix. Frozen repos get `ARCHIVED.md`.
8. **DRAFT** files have no authority until the marker is removed.
9. **Blueprint gate** for new Program deep drafts (Product Confirmed or founder waiver).
10. **AI sessions** load TAXONOMY + REPO_MAP + this repo's README first.
