# Agentic AI on GCP — Curriculum

**Week model (locked 2026-10-03):** Modules 1–6 = live taught content; Modules 7–8 = capstone stubs. Titles below match `Modules/Module_N/README.md`.

## Topics by Week / Module

**Week 1 — Module 1: Agentic AI Foundations, LLM Basics & Data Pipelines**
Building autonomous AI agents; Enterprise AI overview; Prompt engineering; Structured outputs; Agent memory and state.

**Week 2 — Module 2: GCP Basics, Embeddings & Vector Databases**
GCP platform fundamentals; Retrieval Augmented Generation (RAG) fundamentals; Embeddings; Vector databases; Data ingestion and indexing pipelines. GitHub-based version control workflow; Function calling; Tool use and integration; ReAct (Reasoning-Planning-Action) loop; Agent memory and state; Autonomous workflows.

**Week 3 — Module 3: GitHub, Tool Calling & Agent Memory**
Version control workflow; function calling; tool use; ReAct loop; agent memory and state; autonomous workflows. (See Module_3 objectives checklist for delivery-level detail.)

**Week 4 — Module 4: Guardrails & Cloud Deployment**
Input/output guardrails; prompt-injection defense; human approval routing; containerize and deploy; auto-scaling and redeploy.

**Week 5 — Module 5: Human Review, Multi-Agent Architecture & Parallel Processing**
Browser-based human review; multi-agent orchestration; handoffs; parallelization; routing; reflection and plan-then-execute patterns.

**Week 6 — Module 6: Model Context Protocol (MCP) & Advanced Guardrails**
MCP servers; secure tool integration; advanced retrieval; observability; evaluator-optimizer loops; integration toward capstone.

**Weeks 7 & 8 — Modules 7 & 8: Capstone (stubs)**
Creation and presentation of the capstone project. Folder content is Plan of Action only until expanded.

## Capabilities (by module, from each module's Objectives Checklist)

**Module 1** — distinguish agentic AI from generative AI/automation; assess business problems for agentic fit; design prompts for structured extraction; enforce schema-validated output; build a traceable persistence layer.

**Module 2** — set up a scoped cloud project; work a version-controlled branch/PR flow; implement RAG; use vector embeddings for similarity matching; give a model callable tools; wire tools and event triggers into a pipeline; apply the ReAct loop; run a pipeline end-to-end with no manual trigger.

**Module 3** — design stateful memory with a live layer plus archive; implement input/output guardrails; detect and block prompt injection with an audit trail; route sensitive actions through human approval; containerize and deploy a live agentic service; configure auto-scaling and auto-redeploy.

**Module 4** — build a browser-based human review interface; decompose a problem into coordinated agents; orchestrate agents with retries and branching; design validated agent handoffs; process inputs concurrently at scale; apply routing logic; apply agent design patterns including reflection; apply a plan-then-execute pattern.

**Module 5** — expose tools/data as standardized servers (MCP); integrate external tools and services; design granular, relevance-ranked retrieval; combine semantic and keyword retrieval; implement an agent-to-agent handoff protocol; build an agent discovery registry; package agent capabilities as reusable skills.

**Module 6** — instrument a system for full observability; build a self-maintaining, failure-isolating pipeline; integrate all components into an end-to-end capstone; run a fully automated workflow; apply agentic automation to a real business process; evaluate/benchmark under load; apply an evaluator-optimizer loop.

Note: Capability bullets above are copied from existing Objectives Checklists and may lag folder titles where content was reordered historically. Objectives Checklists remain the verification source until a pedagogy rewrite.
