# Module 8 Plan of Action

## Purpose

Module 8 will be the last in the course and will focus on ensuring the preparation of the capstone project for final submission.

By the end of the module, students should have a completed project, an updated GitHub repository, a detailed project report, and a running project demo video.

## What will happen in Module 8

- **Project Completion**

  - Students will complete the remaining parts of their capstone project.
  - The features discussed in Module 7 should be completed and tested.

- **GitHub Repository**

  - The complete project code should be pushed to GitHub.
  - The repository should have a clean folder structure and an updated README.
  - Students should make sure the final version of the project is available in the repository.

- **Final Project Review**

  - The team will review the completed project.
  - The project will be checked for basic functionality, completeness, and alignment with the original problem and solution.
  - Any final corrections or improvements can be made before submission.

- **Detailed Project Report**

  - Students will prepare and submit the detailed project report.
  - The report should cover the project from the initial problem to the final result.
  - The report should not be more than **20 pages**.

- **Running Project Demo Video**

  - The final project demo video will be shot on the same day.
  - Students will start by explaining the problem being solved and the software and technologies used.
  - They will then show the actual project running, provide the input, show how the input is processed, and finally show the output.

- **Final Deliverables Check**

  - The team will check that all required project files, links, videos, and documents have been submitted.
  - Students should make sure all links are working and the final versions of their files are available.

## Final Project Report Structure

The report should be simple, clear, and within the 20 page limit.

- **Introduction** — Basic background and overview of the project.
- **Problem Statement** — Detailed description of the problem being solved.
- **Proposed Solution** — Explanation of the solution built.
- **Project Workflow** — Step-by-step working of the system.
- **System / Architecture** — Main components and how they connect.
- **Technologies Used** — Tools, technologies, frameworks, and platforms used.
- **Implementation** — How the project was built.
- **Results** — Final output and results achieved.
- **Challenges Faced** — Main challenges faced during development.
- **Future Improvements** — Features or improvements that can be added later.
- **Conclusion** — Short summary of the project and its outcome.

## Expected Outcome

By the end of Module 8, every student should have:

- A completed and working capstone project.
- A complete GitHub repository with the final code.
- A detailed project report of maximum 20 pages.
- A recorded running project demo video.
- All final deliverables submitted and checked.
