# Module 4 — Objectives Checklist

Generic outcome checklist for Module 4 (Guardrails & Cloud Deployment), drawn from its Topics list in `Curriculumdetailed.md`.

- [ ] Students will be able to implement guardrails that validate both inputs and outputs before they take effect.
- [ ] Students will be able to detect and block prompt-injection attempts with a full audit trail.
- [ ] Students will be able to containerize and deploy an agentic pipeline as a live, callable service.
- [ ] Students will be able to configure automatic scaling and redeployment for a deployed agent service.
- [ ] Students will be able to apply core cloud deployment fundamentals to host an agentic system in production.
