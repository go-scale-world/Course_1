# Module 2 — Objectives Checklist

Generic outcome checklist for Module 2 (GCP Basics, Embeddings & Vector Databases), drawn from its Topics list in `Curriculumdetailed.md`.

- [ ] Students will be able to set up a cloud project with properly scoped access controls and core platform services.
- [ ] Students will be able to implement retrieval-augmented generation fundamentals to ground system behavior in existing data.
- [ ] Students will be able to generate vector embeddings from text for semantic similarity matching.
- [ ] Students will be able to use a vector database to store and query embeddings for nearest-neighbor matching.
- [ ] Students will be able to build a data ingestion and indexing pipeline that converts raw text into a queryable vector index.
