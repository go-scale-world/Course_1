# Module 7 Plan of Action

## Purpose

Module 7 will focus on getting the students to present their capstone idea, show their current progress, and get an initial review of their project.

By the end of the module, students should have a clear project presentation and around 70% of their project completed and pushed to GitHub.

## What will happen in Module 7

- **Project Presentation**

  - Students will prepare and present a complete project presentation.
  - The presentation should explain the project from the problem to the proposed solution and current progress.

- **GitHub Progress**

  - Students will share their GitHub repository link.
  - Around 50% of the project should be completed and available in the repository.
  - The repository should have the basic project structure and README in place.

- **Project Review**

  - The team will review the current project progress.
  - We will check whether the project is moving in the planned direction and identify any gaps that need to be worked on in Module 8.

- **Presentation Video**

  - Students will record their project presentation on the same day.
  - The video will cover the PPT presentation and the explanation of the project.

- **Deliverables Communication**

  - An email covering the required deliverables and expectations will be shared with students before Module 7.
  - This will give students time to prepare their presentation, GitHub repository, and project progress.

## Final Presentation Structure

The final presentation should be around **10 to 12 slides**. Larger sections can use two slides where needed.

- **Slide 1: Title Slide**

  - Project name
  - Student name
  - Course name
  - Basic project details

- **Slide 2: Project Overview**

  - Short introduction to the project
  - What the project is about
  - Main purpose of the project

- **Slide 3: Problem Statement**

  - Problem being addressed
  - Current situation or difficulty
  - Why this problem needs a solution

- **Slide 4: Proposed Solution**

  - Solution being built
  - How the solution addresses the problem
  - Main outcome expected from the project

- **Slide 5: Project Workflow**

  - Overall flow of the project
  - Main steps from input to output
  - Simple workflow diagram

- **Slide 6: System / Architecture**

  - Main components of the system
  - How the different parts connect
  - Basic architecture or system diagram

- **Slide 7: Technologies Used**

  - Programming languages
  - Frameworks and libraries
  - Cloud platforms, databases, APIs, or other important tools

- **Slide 8: AI / Agentic AI Approach**

  - Where AI is being used
  - What the agent or AI system is responsible for
  - Main AI components used in the project

- **Slide 9: Current Progress**

  - What has been completed so far
  - Features that are currently working
  - Screenshots or a short view of the current system

- **Slide 10: Project Demo / Working**

  - Show the current working part of the project
  - Input and output where possible
  - Brief explanation of the working flow

- **Slide 11: Challenges and Learnings**

  - Main challenges faced so far
  - How the team handled them
  - Important things learned during development

- **Slide 12: Next Steps**

  - Remaining work
  - Features to be completed
  - Improvements planned for Module 8
  - Expected final outcome

The presentation should use **simple visuals, diagrams, screenshots, and short points** instead of putting large amounts of text on the slides.

## Expected Outcome

By the end of Module 7, every student should have:

- A complete project presentation.
- Around 50% of the project completed.
- A working GitHub repository with the current project code.
- A recorded project presentation video.
- Clear points to work on before the final submission in Module 8.
