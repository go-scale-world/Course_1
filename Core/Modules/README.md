# Modules

Rough idea of what goes here: the canonical, single-copy content for all 6 weekly modules (EPR Agentic AI course, condensed 6-week plan). This is the source of truth taught across every cohort — cohort-specific changes get logged in that cohort's `Content_Updates.md`, not forked here. Full plan: `Core/Curriculum.md`.

## Index

- `Module_1/` — Introduction to Agentic AI and Models & Enterprise AI Landscape and Data Foundations
- `Module_2/` — Semantic Understanding through Embeddings & Autonomous Tool Use and Event-Driven Pipelines
- `Module_3/` — Stateful Memory with Firestore & Guardrails and Enterprise Safety
- `Module_4/` — Deployment and Human-in-the-Loop Interfaces
- `Module_5/` — Multi-Agent Orchestration and Parallel Scoring
- `Module_6/` — Enterprise Tool Integration via MCP & Model Fine-Tuning for Enterprise Context & Capstone and Production Readiness

Each module folder's own README also carries its title at the top, so this index staying stale doesn't break navigation.
