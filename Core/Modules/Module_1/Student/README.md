# Module 1 — Student Materials

Student-facing content for this module.

- `lab notes file` — Contains notes for after lab, in a summarzied manner of what was covered in lab.
- `skeleton notes file` — Contains markdown intermediate implementation of skeleton notes for that week. A sheet will be given to students to fill during the start of each session, it will behave as guided notes.
- `notes file` — Contains summarized notes for the weekly topics covered.
