# Module 3 — Objectives Checklist

Generic outcome checklist for Module 3 (GitHub, Tool Calling & Agent Memory), drawn from its Topics list in `Curriculumdetailed.md`.

- [ ] Students will be able to follow a version-controlled branch/PR workflow for collaborative development.
- [ ] Students will be able to equip a model with callable tools it can invoke autonomously.
- [ ] Students will be able to integrate external tools and event triggers into an automated pipeline.
- [ ] Students will be able to apply a reasoning-action (ReAct) loop that interleaves reasoning with tool calls.
- [ ] Students will be able to design a stateful memory layer that tracks live state alongside a historical archive.
- [ ] Students will be able to build a pipeline that runs end-to-end without manual triggering.
