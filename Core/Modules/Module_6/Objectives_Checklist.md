# Module 6 — Objectives Checklist

Generic outcome checklist for Module 6 (Model Context Protocol & Advanced Guardrails), drawn from its Topics list in `Curriculumdetailed.md`.

- [ ] Students will be able to expose tools and data sources as standardized servers callable by any agent with no custom integration.
- [ ] Students will be able to structure the context passed to an agent through a standardized tool-calling protocol.
- [ ] Students will be able to apply a second guardrail layer that screens outbound agent actions before they reach external systems.
- [ ] Students will be able to scope a tool integration to the minimum permissions an agent needs.
- [ ] Students will be able to package an agent's capabilities as a modular, reusable skill attachable to other agents.
- [ ] Students will be able to integrate multiple enterprise tools into an agent's workflow through a standardized protocol.
